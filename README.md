## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 설문·테스트형 서비스부터 사내 업무 시스템까지 다양한 웹 애플리케이션을 빠르게 구축할 수 있습니다.
